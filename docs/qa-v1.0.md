## 自動検証

`npm test` 11件成功。上昇と落下、上下のカメラ追従、羽ばたきの連打制御、成長選択中の完全停止、実際の追尾弾による撃破と経験値回収、光輪と雷撃の独立ダメージ、岩の衝突と無敵時間、回復と上限、150秒のボス出現と連続上昇への追従、縦画面の座標、90秒後のオブジェクト上限、破損・拒否された保存を確認。

最後の通しテストでは、1100×640と390×844の両方で、初期体力・初期武器から開始。1ボタン相当の羽ばたきと実際の成長カード選択のみで、敵の攻撃を受け、回復灯を回収して、ボス撃破まで進行した。無敵・初期強化・敵HPの変更はなし。時間は約2分37秒〜2分44秒。シード17を使用。全シード・全強化構成でのクリア保証ではない。

## ブラウザーでの確認

Cloud Chromeの実画面、通常のボタン・Space入力を使用した。

- 本番入口から開始、自動前進、タップ、長押し、離した後の自然落下。高度表示と背景の両方向スクロールを確認。
- 自動追尾弾の発射と撃破、経験値の表示。
- 844×390の横画面と390×844の縦画面。タイトルのボタン・フッター、3枚の成長カード、HUD、上昇ボタンが表示領域内にあることを確認。
- レベルアップ時の3択、雷撃・体力カードの選択と飛行への復帰、一時停止と再開。
- 中盤の敵の群れ、光輪・連鎖雷撃、ボスとゲージ、ゲームオーバー・クリアの結果画面、リトライでLV1・100HP・02:30へ初期化。
- ページを離れた時の自動停止。検証終了時点でゲーム由来のコンソール警告・エラーはなし。ブラウザー拡張機能由来のエラーは除外。

通常操作の確認と、後半の表示確認は区別している。後半の画面遷移は `tests/qa-bridge.mjs` から明示的なテスト状態を読み込み、本番と同じ `Flight` / `start` / `Painter` で確認したもの。ブラウザーで最初から最後まで手動攻略した記録ではない。

## 確認して修正した点

- 小さい横画面でタイトル下部が切れたため、コピー・見出し・フッターの高さを調整。
- 縦画面でタイトルと自機イラストが重なったため、イラストを上方へ移動。
- 月の切り抜きから不要な外形が出たため、円の内側でクリップ。
- 長押しで大きく上昇するとボスが遅れて画面外へ消え得たため、上下の追従速度とボスの保持条件を修正。
- 狭い画面で初期武器が画面外の敵を先に倒しやすかったため、星弾の自動照準を可視領域に限定。
- 操作を覚える前の待ち時間を減らすため、最初の敵を前方に配置。
- 成長後の立て直し手段として、25撃破ごとの回復灯を追加。エリート撃破時にも回復。
- 他のボタンがSpaceで選べるよう、非飛行中は標準のボタン操作を妨げない。
- 保存APIへのアクセス自体が拒否されても起動が止まらないよう、アクセスを例外処理内へ移動。
