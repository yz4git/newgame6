# Lumen Wing v1.1 / 宇宙艇への変更とテンポ調整

2026-10-25（日本時間）。ユーザー指定の虫モチーフ廃止と、少し速いテンポへの調整。

## 変更

- 自機を固定装甲・2基のエンジン・青いキャノピーを持つ宇宙艇「ルーメン01」に変更。可動する生物の翅や触角、翅の模様は削除。上昇入力では下向きスラスター、前進では後方への噴射が見える。
- 全敵を偵察ドローン、襲撃艇、旋回砲台、装甲母艦、環状武装付き大型艦として再描画。触手・羽ばたきは不使用。タイトル・強化名・説明・アイコンも変更。
- 水平の前進速度を15%増加。星弾の基本間隔は0.58→0.50秒、追尾速度は620→700。経験値の初期吸引速度は350→400。最初の敵は460→410の位置へ移動し、通常の敵出現開始は0.80→0.65秒に短縮。
- 重力510、上昇時速度−255、長押し0.23秒間隔、敵ダメージ・出現頻度の曲線、ボス出現150秒は維持。
- 保存キーは `lumen-wing-v1` のままで過去の記録を引き継ぐ。全実行モジュール・スタイル・manifest・SVGアイコンのURLとSWキャッシュをv1.1に更新。

## 確認

既存の動作テスト11件が成功。上下の物理とカメラ、停止と復帰、自動射撃、経験値、旋回武器と雷撃、被弾・岩・回復、ボス追従、保存拒否、縦横の通しクリアを確認。

速度が変わると遭遇・撃破・成長の順序も変わるため、通しクリアの固定シナリオをシード302へ更新した。無敵・初期強化は与えず、0.97秒周期の通常入力と実際の成長選択のみで、横1100×640で約162秒、縦390×844で約157秒のボス撃破を確認した。すべてのランダムシードを固定入力だけでクリアできるという意味ではない。

旧版と新版に同じ入力を10秒間与える独立した比較では、前進距離1085.56→1248.39（15%増）。機体Yは両方−117.583、カメラYは両方−429.455で一致。敵を出さず射撃タイマーの機会を数えた比較では18回→20回。この計測は操作・タイマーの比較であり、実戦の撃破数や実機フレームレートの測定ではない。

Cloud Chromeの通常入口から実際に開始し、Spaceによる上昇・離した後の落下、上下スクロール、自動撃破、一時停止を確認。844×390の戦闘と390×844のボス・強化画面も表示確認した。後半は明示的なQA状態からの確認で、手動による全編攻略ではない。

最終確認時、ゲーム由来のコンソール警告・エラーはなし。`npm run check` と `git diff --check` を実施。本番配信物に `_qa-*` を含めない。iPhone実機の性能・タッチ・PWA更新は未実測。
