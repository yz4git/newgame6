## 探索

月下の回廊から紅の礼拝堂へ。礼拝堂を拠点として水没書庫と沈黙の鐘楼を探索し、二つの月印で聖域の封印扉を開きます。月銀の鎖は鞭の射程と威力を上げます。敵の討伐で経験値とソウルを獲得し、青い燭台で全回復・保存・強化・転移できます。

槍兵の正面の盾は、背後からの攻撃・三連撃の最後・魔法で崩せます。侍祭の射線と敵の赤い予兆、床に出る月炎の警告を見て、回避や跳躍を使い分けてください。

## 操作

| 操作 | タッチ | キーボード | 標準ゲームパッド |
| --- | --- | --- | --- |
| 移動 | 左右ボタン（指を滑らせて変更可） | ← → / A D | 左スティック / 十字 |
| 二段ジャンプ | 跳躍 | Space / Z | A |
| 鞭・三連撃 | 攻撃（長押し可） | J / X | X |
| 無敵回避 | 回避 | K / Shift | B |
| 月光魔法 | 魔法 | L / C | RB |
| 足場を降りる | ⌄ | ↓ / S | 十字下 |
| 扉・燭台・手記 | 近くで表示される ↑ | ↑ / W / E | Y |
| 回復薬 | 左上の薬 | H | LB |
| 地図 | 右上の地図 | M | — |
| 一時停止 | 右上の Ⅱ | Escape | Start |

移動・攻撃・跳躍は同時に入力できます。地上の攻撃中は踏みとどまり、空中では移動しながら攻撃できます。iPhoneでは横画面を推奨。Safariの共有メニューからホーム画面へ追加できます。初回はオンラインで全素材を読み込んでください。

## 保存

進行はこの端末・この配信元のブラウザーに保存します。死亡や終了時も収集物・成長は残り、再開位置はチェックポイントです。同じ配信元のv1セーブを自動で移行します。GitHub Pagesなど別の配信元へは、設定のJSON書き出し／読み込みで移せます。

新しい旅やセーブ読み込みの前には、ゲーム内に置き換え確認を表示します。保存に失敗した場合も通知し、JSONを書き出せます。設定画面のスライダーとメニューはタッチで操作・スクロールできます。

## 構成と確認

- `dist/content.mjs`: 領域・敵・手記・強化の定義。
- `dist/model.mjs`: DOMに依存しない60Hzの移動・戦闘・探索シミュレーション。
- `dist/render.mjs`: Canvas 2D、透過アトラス、多重スクロール、光・霧・命中演出。光のテクスチャを再利用し、描画品質を調整します。
- `dist/animation.mjs` / `dist/pose-data.mjs`: 足・手の基準点、姿勢選択、鞭の形状と接触判定。
- `dist/main.mjs`: マルチタッチ、キーボード、ゲームパッド、画面遷移、HUD。
- `dist/storage.mjs`: セーブ検証、旧版移行、バックアップ、JSON、設定。
- `dist/audio.mjs`: Web Audioによるオリジナル音楽と効果音。最初の操作で音声を開始。
- `dist/sw.js`: リリース全体を事前キャッシュ。モジュールのバージョンを統一。

```sh
npm test
npm run check
```

外部パッケージ・CDN・分析送信・サーバー保存はありません。描画はDPRと粒子数を制限し、低速時の自動描画調整と省電力設定を備えます。アプリ切り替え時は入力を解除して一時停止します。

Nodeで戦闘・移動・全足場ルート・守り人・強化・転移・ボス全攻撃・セーブ移行／破損復旧・オフライン依存関係を検証。クラウドブラウザーの844×390で開始、描画、戦闘、強化購入、転移、設定変更、スクロール、JSONの書き出し／読み込みを確認しています。iPhone実機のフレームレート・マルチタッチ・音声・オフライン起動とゲームパッド実機は未計測です。

## 美術

本作専用に組み込み `image_gen` で生成した高密度のピクセルペイント素材を使用。粗い8bit風の拡大表示にはしていません。背景・人物・敵・小物を別々のレイヤーとして描画し、人物と敵は姿勢の違うフレームで動きます。画像の包装処理は透過を保つWebP圧縮とアトラス座標の計測です。

初版の仕様は `art-prompts.json`、v2の走行・待機、追加敵、最終聖域は `art-prompts-v2.json`、v2.2の攻撃8コマは `art-prompts-v22.json`。素材はすべて `dist/assets/` に収録しています。

既存ゲームのプログラム・音声・画像は使用していません。見本のゴシック美術と探索アクションの方向性をもとに制作したオリジナルゲームです。
