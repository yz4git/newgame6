# NOCTURNE — 月蝕の聖堂

繊細なゴシック美術とフレームアニメーションで描く、iPhone横画面向け探索アクション。

## 遊ぶ

プレイURL（Sites版）: https://nocturne-eclipse.yzgame.chatgpt.site

GitHub Pages版は公開待ちです。現在は上のURLからプレイしてください。

ルートの `index.html` から `dist/` に移動します。ビルド不要。`dist/` をそのまま静的配信できます。

## ゲーム

- 月下の回廊 → 紅の礼拝堂を拠点に、水没書庫と沈黙の鐘楼を探索。
- 二つの月印を集め、月蝕の聖域で弔鐘の大司教ヴェスパーと戦う。
- 鞭の三連撃、可変高度の二段ジャンプ、無敵回避、月光魔法、回復薬。
- 騎士の斬撃予兆、コウモリの急降下、ボスの追撃・扇状弾と第二段階。
- 月銀の鎖、宝箱、経験値、レベルアップ。燭台で全回復・自動保存。
- 死亡時も獲得済み月印と成長を保持。ボス撃破後も探索可能。

## 操作

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 移動 | 左右ボタン | ← → / A D |
| 二段ジャンプ | 跳躍 | Space / Z |
| 鞭・三連撃 | 攻撃（長押し可） | J / X |
| 無敵回避 | 回避 | K / Shift |
| 魔法 | 魔法 | L / C |
| 扉・燭台 | 近くで表示される ↑ | ↑ / W / E |
| 回復 | 左上の薬 | H |
| 地図 | 右上の地図 | M |
| 一時停止 | 右上の Ⅱ | Escape |

移動と攻撃・跳躍はマルチタッチで同時操作できます。横画面推奨。ホーム画面追加用マニフェストとオフライン用Service Workerを含みます。初回はオンラインで素材を読み込んでください。

## 構成

- `dist/model.mjs`: DOMから独立した60Hz固定更新、移動・戦闘・敵AI・探索・保存。
- `dist/render.mjs`: Canvas 2D、多重スクロール、生成アニメーションアトラス、燭火、霧、光、ヒット演出。
- `dist/main.mjs`: Pointer Events、UI、保存、ロード、ゲームループ。
- `dist/audio.mjs`: Web Audioのオリジナル楽曲と効果音。最初の操作でAudioContextを開始。
- `dist/assets/`: 高密度の美術素材をWebPで収録。透過アトラスを使用し、粗い低解像度への縮小拡大はしません。
- `tests/game.test.mjs`: 二段ジャンプ、着地、連撃、回避、足場ルート、封印、保存、ボス勝利のシミュレーション検証。

```sh
npm test
npm run check
```

外部パッケージやCDNは不要です。DPR上限1.75、粒子数制限、最小限のHUD更新でスマホ負荷を抑えています。アプリ切替時は入力を解除して一時停止し、復帰時に経過時間が一度に進まないようにしています。

## 美術

組み込み `image_gen` で本作専用に生成。プロンプト全文は `art-prompts.json` に保存しています。背景・人物・敵・小物を独立した描画レイヤーとして使用し、人物と敵は姿勢の異なるフレームを切り替えて動かしています。画像の変換はWebPへの圧縮とアトラス座標の計測です。

最終素材: `dist/assets/cathedral.webp`, `crypt.webp`, `belfry.webp`, `hero.webp`, `enemies.webp`, `props.webp`, `atlas.json`。

既存ゲームのプログラム、音声、画像は使用していません。見本のゴシック美術と探索アクションの方向性をもとに制作したオリジナルゲームです。
