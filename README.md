# LUMEN WING — 星を継ぐ翼 / v1.1

`yz4git/newgame6` の新作。フラッピーバードの1ボタン飛行と、ヴァンサバ型の自動攻撃・経験値成長を組み合わせたブラウザーゲームです。旧作「余白航路」のコード・ゲーム性・素材は入れ替えました。

## v1.1 の変更

虫の意匠を全面的に外し、自機・全敵・ボス・アイコン・タイトル・強化名を宇宙艇と浮遊兵器に統一しました。外部画像を使わず、同じCanvas描画で噴射と装甲をアニメーションさせます。

前進速度を15%アップ。基本の自動射撃間隔を0.58秒から0.50秒へ短縮（発射頻度16%増）、追尾弾を約13%高速化し、経験値の吸引を速くしました。最初の敵も少し近くに配置しました。上昇の強さ・重力・長押しの間隔・ボス出現の2分30秒は維持しています。

## 遊び方

画面をタップ、上昇ボタン、Space / ↑ / W のいずれかで下向きスラスターを噴射します。長押しでは約0.23秒ごとに連続噴射。離すと重力で落下し、自動で前進します。カメラは実際の高度と上下速度に追従し、空には天井・床の制限がありません。背景、浮遊遺跡、雲、星は奥行きごとに速度を変えてスクロールします。

攻撃は自動で近くの敵を狙います。緑の灯は経験値。近くの灯や通過した灯は吸い寄せられます。レベルアップで時間が止まり、3枚のカードから力を選択します（1 / 2 / 3 またはクリック・タップ）。ピンクの敵弾と浮遊岩を避け、2分30秒後に出現するボス「星喰い」を倒すとクリア。体力が0になると飛行終了です。敵25体ごとに回復灯、エリート撃破でも回復します。

7種類の成長：星弾の威力・射撃間隔・同時弾数、旋回光輪、連鎖雷撃、経験値吸引、最大体力と修復。最長飛行時間・最多撃破数・クリア数とサウンド設定をこのブラウザーに保存します。

P / Esc またはⅡで一時停止。画面やタブを離れても停止します。サウンドは初期OFF、♪から切り替えます。タイトルの「飛び方」に操作説明があります。スマートフォンの縦・横表示とセーフエリアに対応しています。

## 開発

依存パッケージ・ビルド工程・外部CDNは不要。`dist/` がそのまま静的配信対象です。

```sh
npm test
npm run check
node scripts/balance.mjs
```

- `dist/model.mjs`：決定的乱数、120Hz物理、自動照準、衝突、敵、成長、ボス、回復
- `dist/render.mjs`：Canvas 2Dの夜空、立体的な雲、蝶の翼、遺跡、弾とエフェクト
- `dist/app.mjs`：固定時間ステップ、ポインター・キーボード、画面遷移、休止
- `dist/audio.mjs`：Web Audioの効果音。素材ファイル・外部音源は不使用
- `dist/storage.mjs`：ローカル記録。破損・保存拒否時もゲームは継続
- `dist/sw.js`：オフライン用アセット。旧作品の同一オリジン内キャッシュを整理

Managed preview は `sites-preview start /workspace/sites/nocturne-eclipse`。実行前にSitesのプレビュー手順を確認してください。

## 検証

11件の動作テストには、入力後の上昇と自然落下・両方向のカメラ移動・全自動攻撃による撃破・経験値・成長中の停止・光輪と雷撃・接触ダメージ・回復・ボス追従・セーブ障害・縦横それぞれで最初からボス撃破までの通しシミュレーションを含みます。無敵や初期強化を与えず、実際の成長カードを選んでクリアする経路を検証しています。

画面確認には `node scripts/prepare-qa.mjs` で一時的に `/_qa-phone.html` を作れます。844×390、390×844のiframeで本番と同じアプリを動かし、戦闘・成長・ボス・終了の明示的なシナリオをボタンで読み込みます。このテスト用状態は通常プレイによる到達記録ではありません。`start(initialFlight)` は本番と同じ画面遷移・モデル・描画を使用します。

配信前に必ず `node scripts/clean-qa.mjs` を実行します。`npm run check` はテスト用ファイルの残存、JavaScript構文、DOM参照、manifest、オフライン全依存ファイルを検証します。実機iPhoneの性能・タッチ・ホーム画面追加・オフラインは未検証です。

## アートと配信

ラスタースプライト・画像生成・外部素材を使わず、全て独自のCanvas/SVG描画です。自機は白い装甲の小型宇宙艇「ルーメン01」。固定装甲・機体に接続した2基のエンジン・青いキャノピーを持ち、上昇入力で下向きの噴射光が出ます。敵は偵察ドローン・襲撃艇・旋回砲台・装甲母艦・環状兵器を備えた大型艦です。低モーション設定時はタイトルの装飾移動を抑えます。音楽ではなく入力・攻撃・収集・成長に反応する短い合成効果音を実装しています。

既存のSitesプロジェクトと閲覧範囲を維持して公開します。`.openai/hosting.json` のIDを変更しないでください。旧作のソースはGit履歴に残ります。
